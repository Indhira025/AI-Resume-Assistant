<h2>📌 About The Project</h2>

<p>
<strong>AI Resume Assistant</strong> is an AI-powered web application designed to help
job seekers improve their resumes, optimize ATS compatibility, match resumes with
Job Descriptions, generate personalized cover letters, and prepare for interviews.
</p>

<p>
The application combines <strong>Python, Streamlit, Ollama, Llama 3.2, NLP, and Prompt Engineering</strong>
to provide an interactive AI-powered career assistance platform.
</p>

<hr>

<h2>🎯 Problem Statement</h2>

<p>
Job seekers often face challenges such as:
</p>

<ul>
  <li>Creating ATS-friendly resumes</li>
  <li>Identifying weaknesses in their resumes</li>
  <li>Matching resumes with specific Job Descriptions</li>
  <li>Writing personalized cover letters</li>
  <li>Preparing for technical and HR interviews</li>
  <li>Identifying missing skills required for a target role</li>
</ul>

<p>
The goal of this project is to provide these capabilities through a
<strong>single AI-powered application</strong>.
</p>

<hr>

<h2>✨ Key Features</h2>

<h3>📄 1. Resume Analyzer</h3>

<p>Upload your resume and receive AI-powered feedback about:</p>

<ul>
  <li>Resume strengths</li>
  <li>Areas for improvement</li>
  <li>Missing information</li>
  <li>Skills</li>
  <li>Professional summary</li>
  <li>Overall resume quality</li>
</ul>

<p><strong>Supported formats:</strong> PDF and DOCX</p>

<hr>

<h3>🎯 2. ATS Score Analyzer</h3>

<p>
Analyze your resume from an Applicant Tracking System perspective.
</p>

<ul>
  <li>Keyword relevance</li>
  <li>Skills matching</li>
  <li>Resume structure</li>
  <li>Job relevance</li>
  <li>Section completeness</li>
  <li>ATS optimization suggestions</li>
</ul>

<hr>

<h3>✍️ 3. Resume Rewriter</h3>

<p>
Improve resume content using AI-powered rewriting.
</p>

<ul>
  <li>Professional summary</li>
  <li>Career objective</li>
  <li>Project descriptions</li>
  <li>Resume bullet points</li>
  <li>Skills descriptions</li>
</ul>

<p>
The goal is to make resume content more
<strong>professional, concise, relevant, and ATS-friendly.</strong>
</p>

<hr>

<h3>🔍 4. Job Description Matching</h3>

<p>
Compare your resume with a specific Job Description to identify:
</p>

<ul>
  <li>Matching skills</li>
  <li>Missing skills</li>
  <li>Relevant keywords</li>
  <li>Job alignment</li>
  <li>Skill gaps</li>
  <li>Improvement recommendations</li>
</ul>

<hr>

<h3>📝 5. AI Cover Letter Generator</h3>

<p>
Generate a personalized cover letter using:
</p>

<pre>
Resume + Job Description
        ↓
   AI Analysis
        ↓
Personalized Cover Letter
</pre>

<p>
The generated cover letter focuses on relevant skills, projects,
experience, and qualifications.
</p>

<p>
Generate interview questions based on the resume and target role.

<h2>⚙️ Installation & Setup</h2>

<h3>1️⃣ Clone the Repository</h3>

<pre>
git clone https://github.com/Indhira025/AI-Resume-Assistant.git
cd AI-Resume-Assistant
</pre>

<h3>2️⃣ Create Virtual Environment</h3>

<pre>
python -m venv .venv
</pre>

<h3>3️⃣ Activate Virtual Environment</h3>

<p><strong>Windows:</strong></p>

<pre>
.venv\Scripts\activate
</pre>

<p><strong>Linux / macOS:</strong></p>

<pre>
source .venv/bin/activate
</pre>

<h3>4️⃣ Install Dependencies</h3>

<pre>
pip install -r requirements.txt
</pre>

<hr>

<h2>🦙 Ollama Setup</h2>

<p>
This project uses <strong>Ollama</strong> with the
<strong>Llama 3.2</strong> model for AI-powered processing.
</p>

<h3>Download Llama 3.2</h3>

<pre>
ollama pull llama3.2
</pre>

<h3>Check Installed Models</h3>

<pre>
ollama list
</pre>

<h3>Start Ollama</h3>

<pre>
ollama serve
</pre>

<hr>

<h2>▶️ Run the Application</h2>

<pre>
streamlit run app.py
</pre>

<p>
The application will normally be available at:
</p>

<pre>
http://localhost:8501
</pre>

<h2>💡 Prompt Engineering Approach</h2>

<p>
The project uses task-specific prompts instead of a single generic prompt.
Each feature has its own prompt designed to guide the LLM toward useful,
structured responses.
</p>

<pre>
Resume
   ↓
Feature Selection
   ↓
Task-Specific Prompt
   ↓
Llama 3.2
   ↓
AI Response
   ↓
Response Processing
   ↓
Streamlit UI
</pre>

<h3>Example: Job Description Matching</h3>

<pre>
Resume + Job Description
          ↓
    Matching Prompt
          ↓
       Llama 3.2
          ↓
 ┌──────────────────────┐
 │ Matching Skills      │
 │ Missing Skills       │
 │ Keywords             │
 │ Recommendations      │
 └──────────────────────┘
</pre>

<h2>🔐 Security & Privacy</h2>

<p>
This project is intended primarily as a learning and portfolio project.
For production use, additional privacy and security controls should be
implemented.
</p>

<ul>
  <li>Validate uploaded files</li>
  <li>Limit file sizes</li>
  <li>Avoid storing resumes unnecessarily</li>
  <li>Avoid logging sensitive resume information</li>
  <li>Use environment variables for secrets</li>
  <li>Sanitize user inputs</li>
  <li>Implement authentication when required</li>
</ul>
